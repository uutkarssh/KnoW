# KnoW — AI for Every Task

> Four AI tools. One platform. Free forever.

KnoW is a free, browser-based AI chatbot platform built for students, writers, developers, and thinkers. No sign-up. No API key. No cost. Just open and use.

---

## Tools

| Tool | What it does |
|------|-------------|
| **Write** | Emails, blog posts, essays, social captions, scripts |
| **Code** | Write, debug, and explain code in any language |
| **Study** | Learn concepts, get quizzed, understand any subject |
| **Plan** | Business plans, roadmaps, strategies, 30-60-90 day frameworks |

---

## Why KnoW?

Most AI tools are scattered, expensive, or require a subscription. KnoW fixes all three:

- **All in one** — four specialized tools in a single clean interface
- **100% free** — powered by Puter.js, no payment or API key ever needed
- **Zero setup** — open the file in any browser and start chatting immediately

---

## Getting Started

No installation. No server. No dependencies to install.

1. Download or clone this repository
2. Open index.html in any browser
3. Pick a tool and start chatting

That's it.

---

## Design Philosophy

KnoW is inspired by the editorial aesthetic of one8.com.

- Black and white only — no color noise
- Zero animations, zero gradients, zero shadows
- Typography-first layout — text is the design
- Sharp corners, instant hover states, heavy whitespace

---

## Features

- Multi-turn conversation with full history per session
- Specialized system prompts per tool for focused output
- One-click quick prompt chips on every page
- Auto-resizing textarea input
- Markdown rendering — bold, italic, headers, bullet lists, code blocks
- Fully mobile responsive with hamburger menu
- Clear chat to reset any session

## Deployment

GitHub Pages
1. Push the repo to GitHub
2. Go to Settings → Pages → select main branch
3. Live at https://your-username.github.io/know-ai

Netlify
1. Drag the project folder into netlify.com/drop
2. Live instantly

Local
Open index.html directly in any browser — no server needed.
